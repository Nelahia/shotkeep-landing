Use cases

Keep the shot. Not the clutter.

ShotKeep is for the gap between taking a screenshot and actually needing it again.

Debugging a UI

Grab every state as you chase a bug — sort them out later, not mid-flow.

Writing it up

Docs, tickets, PRs — every screenshot is already organized when you need it.

Pairing & demos

Clipboard captures (⌘⇧⌃4) land in the vault too, not just on-screen.

A clean Desktop

Nothing on it but the files you actually put there yourself.

No new shortcuts

Same keys. Different destination.

ShotKeep doesn't add shortcuts to learn — it watches the four you already use and redirects the result.

How it works

One shortcut in. A tidy folder out.

Two watchers run quietly in the background so you never have to think about either path.

⌘⇧3or⌘⇧⌃4
01

Capture

Press the shortcut you already use. Nothing new to learn, no app to open first.

FSEvents + clipboard · watching
02

Catch

FSEvents watches your screenshot folder; the clipboard is polled every 0.8s. Either way, ShotKeep notices instantly.

→ ~/ShotKeep
03

Keep

The file is moved into one folder automatically. Your Desktop never sees it.
